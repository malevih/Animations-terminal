# Animations Terminal

Анимированные инфографики в стиле терминала. Каждая анимация — это один статический `index.html` в своей папке, без сборки и зависимостей.

Сайт: https://malevih.github.io/Animations-terminal/

| Папка | Что показывает |
|---|---|
| [`/ai`](ai/) | Серия **AI Engineering**: как устроены LLM. Готово: [`/ai/tokenization`](ai/tokenization/) — настоящий BPE на учебном корпусе (пары → слияния → словарь → id → эмбеддинги); [`/ai/embeddings`](ai/embeddings/) — skip-gram с negative sampling обучается в браузере, слова собираются в смысловые группы; [`/ai/attention`](ai/attention/) — self-attention с causal mask на настоящей математике; [`/ai/transformer`](ai/transformer/) — настоящий мини-трансформер генерирует текст в браузере; [`/ai/moe`](ai/moe/) — mixture of experts: роутер отправляет токен к 2 из 4 экспертов; [`/ai/kv-cache`](ai/kv-cache/) — генерация с пересчётом и с KV-кэшем на той же модели; [`/ai/speculative`](ai/speculative/) — черновик угадывает, большая модель проверяет за один проход; [`/ai/batching`](ai/batching/) — continuous batching против обычного; [`/ai/chunking`](ai/chunking/) — semantic chunking на эмбеддингах MiniLM против нарезки по символам; [`/ai/bm25`](ai/bm25/) — Okapi BM25 в браузере; [`/ai/hybrid`](ai/hybrid/) — BM25 + векторный поиск со слиянием RRF; [`/ai/query-rewriting`](ai/query-rewriting/) — LLM переписывает вопрос, поиск по всем вариантам. [`/ai/rag`](ai/rag/) — полный RAG-пайплайн с проверкой цитат. Re-ranking — в ожидании: нужен доступ к Hugging Face для модели cross-encoder. Разделы серии: модель → инференс → поиск и RAG → агенты → продакшен |
| [`/trading`](trading/) | Неделя трейдера: стратегия + график + опыт → анализ → вход → контроль эмоций → трейд-журнал → разбор в выходные |
| [`/leads`](leads/) | Заявки с сайта: бриф заказчика → сайт с формой → Telegram-бот → чат фирмы → менеджер звонит клиенту |

## Как добавить новую анимацию

1. Создать папку, например `/onboarding`, и положить в неё `index.html`.
2. Добавить карточку со ссылкой в корневой `index.html`.
3. Запушить в `main`, через 1–2 минуты GitHub Pages обновит сайт.

## Как поменять данные

- **trading**: массив `TRADES` в `<script>`. Цена задаётся в единицах R (стоп = −1, тейк = `rr`), эмоции привязаны к индексу точки на `path`. Итоги разбора недели записаны текстом в HTML, после изменения сделок их нужно поправить вручную.
- **ai/tokenization**: корпус в `CORPUS`, число слияний в `MAX_MERGES`, текст для кодирования в `NEW_TEXT`. Алгоритм BPE выполняется в браузере, поэтому пары, частоты, словарь и id всегда настоящие для заданного корпуса. Векторы эмбеддингов — детерминированные учебные числа, а не обученные веса.
- **ai/embeddings**: корпус собирается из шаблонов в начале `<script>` (группы `G`), гиперпараметры в `WIN`, `D`, `EPOCHS`, `NEG`, `LR`. Обучение настоящее (skip-gram, negative sampling, фиксированный seed, поэтому каждый круг одинаковый); соседи считаются по косинусу в 8D, на графике — проекция 8D → 2D через PCA. Цвета групп заданы нами для наглядности, модель их не знает.
- **ai/attention**: предложение в `TOK`, признаки токенов в `E`, веса в `WQ` и `WK` (заданы вручную для наглядности, `W_V` — единичная). Счёт Q·Kᵀ/√d, маска, softmax, смешивание V и residual вычисляются в браузере.
- **ai/transformer**: модель (2 слоя, 2 головы, d = 32, 27 810 параметров) обучена скриптом [`ai/transformer/train.py`](ai/transformer/train.py) (JAX, синтетический корпус из 42 предложений); веса вшиты в страницу как JSON, прямой проход написан на JS и сверен с Python (расхождение < 1e-5). Промпты — массив `PROMPTS`, выбор токена — сэмплирование с фиксированным seed. Чтобы переобучить: `pip install "jax[cpu]"`, `python train.py`, затем подставить `tf_weights.json` в `<script id="weights">`.
- **ai/moe**: та же архитектура, но во втором слое 4 эксперта и роутер top-2, обучено скриптом [`ai/moe/train.py`](ai/moe/train.py) с балансирующим loss (как в Switch Transformer). Статистика «кому что достаётся» считается в браузере при загрузке: страница прогоняет модель по обучающему корпусу.
- **ai/kv-cache**: веса — те же, что у `ai/transformer`. Два прохода (`full` и `step` с кэшем) выполняются в браузере, умножения считает счётчик `OPS` внутри кода, совпадение logits проверяется на каждом шаге. Промпты — массив `PROMPTS`, выбор токена — greedy.
- **ai/speculative**: большая модель — та же, что у `ai/transformer`; черновик (1 слой, d = 16, 4 562 параметра) обучен скриптом [`ai/speculative/train_draft.py`](ai/speculative/train_draft.py). Жадный speculative decoding с k = 4 выполняется в браузере, страница сравнивает итог с обычной жадной генерацией. Промпты — массив `PROMPTS`.
- **ai/batching**: запросы — массив `REQ` (промпт и шаг прихода), ответы генерирует модель со страницы transformer прямо в браузере. Два планировщика (`simulate('static')` и `simulate('continuous')`) идут по одним часам, число слотов в `SLOTS`.
- **ai/chunking**: эмбеддинги 20 предложений посчитаны моделью all-MiniLM-L6-v2 скриптом [`ai/chunking/embed_doc.py`](ai/chunking/embed_doc.py) (ONNX, модель из npm-пакета `@xcidos/genesis-memory-model`) и вшиты в страницу. Расстояния окно-к-окну (`K` = 2), пики, порог и сравнение с нарезкой по `FIX` = 200 символов считаются в браузере.
- **ai/bm25**: корпус — те же 20 предложений, что в `ai/chunking`. Токенизация, IDF и счёт Okapi BM25 (`K1` = 1.2, `B` = 0.75) считаются в браузере, запросы — массив `QUERIES`.
- **ai/hybrid**: эмбеддинги 14 запросов и ручная разметка правильных чанков — скрипт [`ai/hybrid/embed_queries.py`](ai/hybrid/embed_queries.py); BM25, косинусы, RRF (`RK` = 60) и общий счёт считаются в браузере. При ничьей в RRF выше ставится чанк с лучшим местом в BM25.
- **ai/query-rewriting**: вопросы, ручная разметка правильных чанков и варианты, написанные Claude в роли переписывающей LLM, — в [`ai/query-rewriting/rewrites.py`](ai/query-rewriting/rewrites.py). Эмбеддинги вопросов и вариантов посчитаны MiniLM заранее; BM25, косинусы и RRF — в браузере.
- **ai/rag**: вопросы, переписанные варианты, ответы с цитатами и ответы «без RAG» (написаны Claude в роли LLM) — в [`ai/rag/rag_data.py`](ai/rag/rag_data.py). Поиск (BM25 + MiniLM + RRF, top-5), номера ссылок и проверка каждого утверждения (цитата дословно в процитированном чанке; для «нет в документе» — отсутствие слов во всём документе) выполняются в браузере.
- **leads**: массив `people` в `<script>` (имя, телефон, услуга). Тексты блоков лежат прямо в HTML.

## Запись видео

Открой страницу на телефоне и запиши экран. Один цикл занимает около 20 секунд у `leads` и около минуты у `trading`.
