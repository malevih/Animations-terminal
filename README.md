# Trader Week Animation

Терминальная анимация недельного цикла трейдера:

**стратегия + график + опыт → анализ → вход → исполнение и контроль эмоций → трейд-журнал → разбор недели в выходные**

Пять торговых дней (пн–пт), по одной сделке в день, затем разбор недели. Полный круг длится около минуты, после чего анимация повторяется.

## Запуск

Это один статический файл `index.html`, без сборки и зависимостей.

- Локально: открыть `index.html` в браузере.
- Онлайн: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Как поменять сделки

Все данные лежат в массиве `TRADES` внутри `<script>` в `index.html`. У каждой сделки есть:

- `pair`, `dir`, `e` / `sl` / `tp`: инструмент и уровни ордера;
- `rr` и `out`: целевой R:R и фактический результат в R;
- `path`: движение цены в единицах R (стоп = −1, тейк = `rr`);
- `emo`: эмоции `[индекс точки на path, эмоция, ситуация, как закрыл]`;
- `note`, `feel`: заметка и эмоция для журнала.

Итоги в блоке «разбор недели» заданы текстом в HTML, поэтому после изменения сделок их нужно поправить вручную.

## Запись видео

Открой страницу на телефоне и запиши экран. Для соцсетей хватит одного цикла.
