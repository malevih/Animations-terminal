MCP · ОДИН РАЗЪЁМ ДЛЯ ВСЕХ ИНСТРУМЕНТОВ

Model Context Protocol — открытый стандарт, как приложение с LLM подключается к внешним инструментам и данным. Сервис один раз пишет MCP-сервер, и им может пользоваться любое приложение, которое умеет MCP: чат, IDE, свой агент.

Две ошибки разного рода. Неверные аргументы — это ошибка выполнения: она приходит как обычный результат с isError: true, модель читает текст и исправляется. Неизвестный инструмент — ошибка протокола JSON-RPC с кодом −32602, такое модель обычно не починит.
Форматы сообщений взяты из спецификации MCP версии 2026-07-28: server/discover, tools/list, tools/call, поля _meta, resultType, isError. Сервер, клиенты и инструменты (поиск по тендеру, календарь банковских дней) работают в браузере. Это учебная реализация небольшой части протокола, не официальный SDK.
