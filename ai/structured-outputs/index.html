STRUCTURED OUTPUTS · СТРОГО ПО СХЕМЕ

Когда ответ модели читает не человек, а код, «примерно JSON» ломает программу. Structured outputs заставляют модель выдавать ответ, который точно проходит схему: на каждом шаге генерации запрещённые токены просто вырезаются.

Перед выбором каждого токена схема превращается в маску: всё, что сделает JSON невалидным, получает вероятность 0. Модель всё ещё выбирает сама, но только из разрешённого. Так работают structured outputs в API и библиотеки вроде Outlines и llguidance.
